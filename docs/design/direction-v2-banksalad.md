## 1. 한 문장과 세 원칙

**한 문장:** 회색 바탕 위 흰 카드, 초록 하나, 가장 큰 글자는 금액. 장식을 덜어서 누가 얼마인지가 먼저 읽히게 한다.

1. **숫자가 주인공이다.** 금액은 화면에서 가장 크고 굵다. 아이콘·색·그림자는 금액보다 먼저 눈에 띄면 안 된다.
2. **초록은 하나, 뜻은 하나.** 초록은 "주요 행동"과 "이익"에만 쓴다. 다른 색은 아이콘 안이나 경고에만 나온다.
3. **납작하게.** 카드·버튼·헤더의 그림자를 빼고 바탕색 차이와 간격으로만 나눈다. 화면 위에 겹쳐 뜨는 것(대화상자, 토스트)만 그림자를 갖는다.

### 2.1 뱅크샐러드의 바탕 대비와 그림자 (실측)

App Store 고해상도 스크린샷(A 01~06, 1260×2736)의 세로선을 1픽셀 간격으로 읽어 색이 바뀌는 지점을 쟀다.

| 관찰 | 측정 | 뜻 |
|---|---|---|
| 바탕과 카드 | 바탕 `#F6F7F9`(일부 `#F7F8FA`), 카드 `#FFFFFF`. 대비 약 1.07:1 | 아주 옅은 차이로만 층을 나눈다 |
| 카드 가장자리 | 바탕 → 카드가 1~2px(안티앨리어싱) 안에 끝난다. 번지는 그림자 픽셀이 없다(01·03·04·05) | **카드 그림자 0** |
| 카드 안 타일 | `#F8F9FB`(01 혜택 타일), 보조 버튼은 `#F2F4F6` 안팎 | 흰 카드 안에서는 바탕보다 더 옅은 회색 |
| 헤더 | 흰 헤더(탭·로고) 바로 아래가 회색 바탕. 구분선 없음(04·05) | **헤더도 색 차이로만** 나눈다 |
| 큰 숫자·제목 위치 | "월 보험료 548,572원"(04), "대출이자 줄이기"·"내 대출 2개"(05), 가계부 월 요약(02)이 회색 바탕에 직접 놓인다 | 회색 바탕이 "제목 층", 흰 카드가 "내용 층" |
| 흰 전폭 구역 | "보험료 줄이는 방법"(04), "조건별 카드 찾기"(06)는 좌우 여백 없는 흰 구역 | 목록이 긴 구역은 전폭도 쓴다 |

## 5. 페이지별 적용

구역의 상대 순서, Spec 문구, §7 문구, FD-12 페이지 구성은 그대로다. 바뀌는 것은 모양뿐이다.

### 5.1 공통 헤더(떠 있는 헤더)

- 흰 바탕, 구분선·그림자 없음(회색 바탕과의 색 차이로 나눈다, §2.1). 왼쪽에 방 이름 20/700, 옆에 진행 상태 배지.
- 그 아래 탭 4개(DV-9). 끊김 중에는 지금처럼 `DDALLANG`만 보인다.

### 5.2 현황(`누적 손익`, `거래 내역`)

- **누적 손익 카드:** 참여자마다 목록 행(DV-11). 오른쪽 금액은 이익 `+` `brandText`, 손실 `−` `ink`, 0은 `ink`(FD-10 부호 그대로). 비활성은 이름 옆 회색 배지. 서버 순서 그대로.
- **거래 내역 카드:** 행 = 아바타(지급자) · "가온 → 나래"(16/400) + 메타(14/500) · 오른쪽 금액(18/700, 부호 없음). 필터는 카드 제목 오른쪽 회색 알약, `더 보기`는 카드 아래 전폭 회색 버튼.
- **`거래 기록하기`:** 화면 아래 고정 전폭 주 버튼 모양의 링크(FD-18 (4) 동작 그대로).

### 5.3 기록(`거래 입력`)

- 한 카드 안에 지급자 → 수취자 선택, 금액 입력(24/700 오른쪽 정렬, 단위 표시). 입력 항목은 지금과 같다(지급자·수취자·금액·사유 (선택)·라운드 (선택)).
- 지급자·수취자 선택은 회색 알약 칩 목록(선택 = `primary` 채움 + 흰 글자). 칩 방식이 접근성 계약(라벨·오류 연결)을 지키지 못하면 지금의 선택 상자를 유지하고 모양만 바꾼다.
- 저장 버튼은 카드 아래 전폭 주 버튼. 저장 안내는 `primarySoft` 띠.

### 5.4 정산(`예상 정산`·`최종 정산`, `게임 종료`)

- 정산 항목 행: "가온 → 나래" 왼쪽, 금액 오른쪽 18/700. 이체 방향은 아이콘이 아니라 글자(`→`)로 전한다.
- 최종 정산 카드 위에 `primarySoft` 띠(게임 종료 배지·복사 버튼). 복사는 회색 알약.
- `게임 종료`는 정산 카드와 구분선으로 떨어뜨린 위험 버튼(테두리형). 확인 대화상자 안에서만 빨강 채움.

### 5.5 방(`방 정보`, `참여자`)

- 방 정보 카드: 라벨(`inkMuted` 14) → 값(`ink` 16/600) 쌍을 세로로 쌓는다. 초대 링크는 `paperSubtle` 타일 안에 한 줄 말줄임 + 오른쪽 회색 알약 `복사`.
- 참여자 카드: 목록 행(DV-11). 방장 컨트롤(비활성화·재활성화)은 행 오른쪽 회색 알약.

### 5.6 방 만들기·초대 입장

- 흰 카드 하나에 제목, 입력, 아래 전폭 주 버튼. 바탕은 `canvas`. 로고(딸랑 코인 아이콘)는 위쪽 가운데 48px.
