## H. 공통 기반 소유·의존 점검

- 같은 기능을 두 Task가 구현하지 않는다: 저장소·잠금은 F3만, 요청·오류·시계는 F2만, Idempotency Key 수명은 F8만, 포맷·복사·모달은 F5만(시각 스타일 개정은 예외로 `FE-D1`이 하며 계약은 바꾸지 않는다), 스트림 파서는 S5-1만, 갱신 주기·스냅샷은 S5-2만, 연결 상태·재연결은 S5-3만 구현한다. 다른 Task는 소비만 한다.
- 시험 Task(`S1-5`, `S1-6`, `S2-4`, `S3-3`, `S5-5`, `S5-6`, `S4-4`, `I1`, `Z1`)는 구현 Task와 다른 ID로 분리해 완료 기준을 독립적으로 판정한다.
- 서버 유래 영역은 모두 `ServerDataGate`(F6) 아래에 둔다. 끊김 중 입력 보존은 폼 초안 원자(S2-2)와 `S5-4`의 책임이다.
- 백엔드 Task와의 선행 관계는 `plan.md` §4.3이다. 모의로 끝낼 수 있는 Task는 백엔드가 준비되기 전에 완료할 수 있다.
