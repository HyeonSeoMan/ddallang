## 1. 한 문장과 세 원칙

**한 문장:** 회색 바탕 위 흰 카드, 초록 하나, 가장 큰 글자는 금액. 장식을 덜어서 누가 얼마인지가 먼저 읽히게 한다.

1. **숫자가 주인공이다.** 금액은 화면에서 가장 크고 굵다. 아이콘·색·그림자는 금액보다 먼저 눈에 띄면 안 된다.
2. **초록은 하나, 뜻은 하나.** 초록은 "주요 행동"과 "이익"에만 쓴다. 다른 색은 아이콘 안이나 경고에만 나온다.
3. **납작하게.** 카드·버튼·헤더의 그림자를 빼고 바탕색 차이와 간격으로만 나눈다. 화면 위에 겹쳐 뜨는 것(확인 대화상자)만 그림자를 갖는다.

## 5. 페이지별 적용

구역의 상대 순서, Spec 문구, §7 문구, FD-12 페이지 구성은 그대로다. 바뀌는 것은 모양뿐이다.

### 5.1 공통 헤더(떠 있는 헤더)

- 흰 바탕, 구분선·그림자 없음(회색 바탕과의 색 차이로 나눈다, §2.1). 왼쪽에 방 이름 20/700, 옆에 진행 상태 배지. 로고 아이콘은 두지 않는다(DV-16).
- 그 아래 탭 4개(DV-9). 끊김 중에는 지금처럼 `DDALLANG`만 보인다.
- **끊김·연결 중(서버 유래 영역이 가려질 때):** 연결 배너는 지금 문구 그대로(제목 + 상세) §3.1 톤의 띠로 보인다. 각 구역은 **바탕 위 제목만** 남고 카드·스켈레톤·대체 문구는 없다(S5 §6.5, 지금의 "제목만 있는 컴팩트 카드"를 DV-13에 맞춘 모양). 게임이 끝나 폼이 없는 거래 입력 구역도 같다.
- 흰 헤더가 스크롤 중 흰 카드 위를 지날 때의 경계는 RV-5로 확인한다.

### 5.2 현황(`누적 손익`, `거래 내역`)

- **누적 손익 카드:** 참여자마다 목록 행(DV-11). 오른쪽 금액은 이익 `+` `brandText`, 손실 `−` `ink`, 0은 `ink`(FD-10 부호 그대로). 비활성은 이름 옆 회색 배지. 서버 순서 그대로.
- **거래 내역 카드:** 맨 위에 참여자 필터 한 줄(DV-17). 행 = 회색 원 안 코인 아이콘(DV-14) · "가온 → 나래"(16/400) + 메타(14/500) · 오른쪽 금액(18/700, 부호 없음). 수정·삭제는 메타 아래 회색 알약(§4 보조 버튼, 터치 44px)(삭제는 `danger` 글자). `더 보기`는 카드 아래 전폭 회색 버튼. **수정 중인 행**은 행 내용 아래에 카드 폭 전체로 수정 폼(지금 입력 항목·버튼 그대로)이 펼쳐지고, 그동안 오른쪽 금액은 그대로 둔다.
- **`거래 기록하기`:** 화면 아래 고정 전폭 주 버튼 모양의 링크(FD-18 (4) 동작 그대로).

### 5.3 기록(`거래 입력`)

- 한 카드 안에 지급자 → 수취자 선택, 금액 입력(24/700 오른쪽 정렬, 단위 표시). 입력 항목은 지금과 같다(지급자·수취자·금액·사유 (선택)·라운드 (선택)).
- 지급자·수취자는 지금의 선택 상자(DV-17). 둘 사이에 `→` 구분선(장식).
- 저장 버튼은 폼 안, 카드 아래 전폭 주 버튼(DV-19). 저장 안내는 폼 카드 맨 위의 success 띠(완료 아이콘 + `거래를 저장했습니다.`)이고, 저장 뒤 폼은 비워진다(U-10, 지금 동작 그대로).

### 5.4 정산(`예상 정산`·`최종 정산`, `게임 종료`)

- 정산 항목은 §4 정산 행(아바타 없음, 구분선). 이체 방향은 아이콘이 아니라 글자(`→`)로 전한다. 예상 정산 안내 문구는 info 띠.
- 최종 정산 카드 위에 `primarySoft` 띠(게임 종료 배지·복사 버튼). 띠 안 배지는 `paper` 바탕 neutral, 복사는 `paper` 바탕 알약(문구 `정산 복사`). 복사 결과는 버튼 아래 상태 문단(토스트 아님). 모든 항목은 같은 행(DV-18).
- `게임 종료`는 정산 카드와 구분선으로 떨어뜨린 위험 버튼(테두리형). 확인 대화상자 안에서만 빨강 채움.

### 5.5 방(`방 정보`, `참여자`)

- 방 정보 카드: **지금 문구 그대로** 세로로 쌓는다. 방 이름(20/700, 라벨 없음) → `정산 단위: 원`(16/400) → 진행 상태 배지 → `내 닉네임: 김철수` + 방장 배지. 새 라벨을 더하지 않는다.
- 초대 링크: 보이는 라벨 `초대 링크` + **지금처럼 readOnly 입력란**(포커스하면 전체 선택, §4 입력 규칙, 긴 링크는 입력란 안에서 잘림) + 그 아래 회색 알약 `초대 링크 복사` + 상태 문단. 복사 실패 문구("링크를 직접 선택해…")가 입력란 선택에 기대므로 입력란을 없애지 않는다.
- 참여자 카드: 목록 행(DV-11). 방장 컨트롤(비활성화·재활성화)은 행 오른쪽 회색 알약.

### 5.6 방 만들기·초대 입장

- 맨 위 `BrandHeader`: 동전 종 아이콘(장식) + h1 `DDALLANG`(**문구 유지**, 접근 가능한 이름 그대로). 그 아래 흰 카드 하나에 카드 제목(지금 문구 그대로: 홈은 `방 만들기`, 입장 화면은 지금 제목), 입력, 아래 전폭 주 버튼. 바탕은 `canvas`. 정산 단위는 선택 상자(DV-17). 글자 `딸랑`으로 바꾸는 것은 문구 변경이라 하지 않는다.
